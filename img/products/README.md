# Creator Shop product images

The product catalog uses image paths under `img/products/`. The JavaScript intentionally references files that you can add yourself later.

Create the folder `img/products` if it does not exist, then put each product image in the matching filename below. Use JPG, PNG, or WebP and keep the filename/path in `js/shop-creator.js` in sync.
