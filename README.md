# Creator Shop

A responsive front-end storefront concept built with HTML, CSS, and vanilla JavaScript. This refresh keeps the original idea and local product imagery while organizing the layout, styles, and interactions into a consistent design.

## Pages

- `shop-creator.html` — storefront, category shortcuts, hero carousel, product search and filters, demo shopping bag, editorial cards, and newsletter feedback.
- `login_creator.html` — responsive sign-in / create-account presentation.
- `shoping.html` — placeholder page retained from the original project.

## Run locally

1. Open the repository on GitHub and choose **Code → Download ZIP**.
2. Extract the ZIP file.
3. Open `shop-creator.html` in a modern browser.

Keep the `css`, `js`, `img`, and `svg` folders beside the HTML files so relative image and stylesheet paths work. Google Fonts are optional; system fonts are used as a fallback.

## Interactions

- Responsive mobile navigation.
- Automatic hero carousel with previous/next controls.
- Product search and category filters.
- Demo shopping bag saved in the current browser when local storage is available.
- Account form switching and demo feedback.

## Important limitations

This is a **front-end practice project**, not a production e-commerce service. There is no backend, real authentication, payment processing, order management, or newsletter endpoint. Do not enter real passwords or payment information. Product names and prices are sample content.
